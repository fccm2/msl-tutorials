xmgk - tutorial - random

random values

img-35.xml

you can start from a very simple base like this

<msl>
  <image>
    <new w='700' h='110' rgb='15,31,127' />
    <draw_rectangle pos='10,20' dims='20,20' rgb='0,0,255' stroke_width='4.0' />
    <write filename='rectangle-05.png' />
  </image>
</msl>

then you would like to position the small square at random positions

<msl>
  <image>
    <new w='700' h='110' rgb='15,31,127' />
    <draw_rectangle pos='10:670,10:85' dims='20,20' rgb='0,0,255' stroke_width='4.0' />
    <display />
  </image>
</msl>

the preprocessor pppr will create x value in the range 10:670

and y values in the range 10:85

./pppr.opt  img-35.xml

as for example

<msl>
<image>
<new w="700" h="110" rgb="15,31,127" />
<draw_rectangle pos="125,58" dims="20,20" rgb="0,0,255" stroke_width="4.0" />
<display />
</image>
</msl>

complete process

$ pppr img-35.xml > img-35.1.xml
$ xmgk img-35.1.xml

$ pppo1.opt img-35.xml > img-35.1.xml
$ pppr.opt img-35.1.xml > img-35.r.xml

with a for loop we can create this nice effect

<msl>
  <image>
    <new w='700' h='110' rgb='15,31,127' />
    <for rnt='55'>
      <draw_rectangle pos='10:670,10:85' dims='20,20' rgb='0,0,255' stroke_width='4.0' />
    </for>
    <display />
    <write filename='rngl-05a.png' />
  </image>
</msl>
